LECTURE NOTES
Lecture 7: CPU Scheduling
- The CPU scheduler picks which process in the ready queue runs next. The dispatcher then hands the CPU to that process through a context switch.
- Preemptive scheduling can take the CPU away from a running process; non-preemptive scheduling lets it run until it blocks or finishes.
- First-Come First-Served (FCFS): processes run in arrival order. It is simple but suffers from the convoy effect, where short processes wait behind one long process.
- Shortest Job First (SJF): runs the process with the smallest next CPU burst. It gives the minimum average waiting time but needs a prediction of burst length and can starve long processes.
- Round Robin (RR): each process gets a fixed time quantum and then goes to the back of the ready queue. If the quantum is very large, RR behaves like FCFS; if it is very small, context-switch overhead dominates.
- Priority scheduling: runs the highest-priority process first. Starvation can be solved by aging, which gradually increases the priority of waiting processes.
- Metrics: turnaround time = completion time - arrival time; waiting time = turnaround time - burst time; response time = first run time - arrival time.
