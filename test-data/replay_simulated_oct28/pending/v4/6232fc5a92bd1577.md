Lecture 2: Algorithm Analysis and Big-O
- Time complexity describes how running time grows with input size n, not the exact number of seconds.
- Big-O gives an upper bound on growth: f(n) = O(g(n)) if there are constants c and n0 such that f(n) <= c*g(n) for all n >= n0.
- Common classes in increasing order of growth: O(1) constant, O(log n) logarithmic, O(n) linear, O(n log n), O(n^2) quadratic, O(2^n) exponential.
- Drop constants and lower-order terms: 3n^2 + 5n + 7 is O(n^2).
- Binary search on a sorted array is O(log n) because each step halves the search range. Linear search is O(n).
- Merge sort is O(n log n) in the worst case. Insertion sort is O(n^2) in the worst case but O(n) when the array is already sorted.
- Big-Omega gives a lower bound and Big-Theta gives a tight bound, meaning both upper and lower.
- Space complexity measures the extra memory used as a function of n.
