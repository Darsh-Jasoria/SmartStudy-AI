Lecture 5: Gradient Descent
- Gradient descent minimises a loss function L(w) by repeatedly moving the parameters w in the direction opposite to the gradient.
- Update rule: w_new = w_old - alpha * dL/dw, where alpha is the learning rate.
- If the learning rate is too small, convergence is slow; if it is too large, the updates can overshoot the minimum and diverge.
- Batch gradient descent computes the gradient on the whole training set at each step: it is stable but slow for large data.
- Stochastic gradient descent (SGD) uses one example per update: it is fast and noisy, and the noise can help escape shallow local minima.
- Mini-batch gradient descent uses a small batch (for example 32 or 64 examples) and is the usual choice in practice.
- For a convex loss such as mean squared error in linear regression, gradient descent with a suitable learning rate reaches the global minimum.
- Feature scaling (for example standardisation) makes the loss surface rounder and speeds up convergence.
- An epoch is one full pass through the training data.
