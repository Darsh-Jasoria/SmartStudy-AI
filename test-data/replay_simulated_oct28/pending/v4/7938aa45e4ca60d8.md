LECTURE NOTES
Lecture 12: Evaluating Machine Learning Models

Part 1: Why we split the data
- A model must be judged on data it has not seen during training. The data is therefore divided into a training set, a validation set and a test set.
- The training set is used to fit the model parameters. The validation set is used to choose hyperparameters and to compare models. The test set is used once at the end to estimate how the final model will perform on new data.
- Using the test set repeatedly to tune the model makes its score optimistic, because the test data has indirectly influenced the model.
- Data leakage happens when information from outside the training data, for example from the test set or from the future, is used to build the model. It produces unrealistically good results that disappear in real use.

Part 2: Overfitting and underfitting
- Underfitting means the model is too simple to capture the pattern in the data. It has high error on both the training set and the test set.
- Overfitting means the model fits the noise in the training data. It has very low training error but much higher error on new data.
- The bias-variance trade-off describes this. High bias means strong simplifying assumptions and leads to underfitting. High variance means the model is very sensitive to the particular training sample and leads to overfitting. Making a model more complex usually lowers bias and raises variance.
- Regularization discourages overfitting by adding a penalty on large weights to the loss. L2 regularization penalises the sum of squared weights, and L1 regularization penalises the sum of absolute weights and can drive some weights to exactly zero.
- Early stopping halts training when the validation error stops improving.

Part 3: Cross-validation
- In k-fold cross-validation the data is divided into k equal folds. The model is trained k times, each time holding out one fold for validation and training on the other k minus 1 folds. The k scores are averaged.
- Cross-validation gives a more stable estimate than a single split and is useful when data is limited, but it costs k times more training.
- A common choice is k equal to 5 or 10.

Part 4: The confusion matrix
- For a binary classifier the confusion matrix counts four outcomes. A true positive (TP) is a positive example predicted positive. A false positive (FP) is a negative example predicted positive. A false negative (FN) is a positive example predicted negative. A true negative (TN) is a negative example predicted negative.
- Accuracy is (TP + TN) divided by the total number of examples.
- Precision is TP divided by (TP + FP). It answers: of the examples predicted positive, how many really are positive?
- Recall, also called sensitivity or the true positive rate, is TP divided by (TP + FN). It answers: of the really positive examples, how many did the model find?
- The F1 score is the harmonic mean of precision and recall, 2 x precision x recall divided by (precision + recall). It is high only when both are high.

Part 5: Class imbalance
- If 99 percent of examples are negative, a model that always predicts negative has 99 percent accuracy but finds no positive cases. Accuracy is therefore misleading for imbalanced data.
- In that situation precision, recall and F1 are better measures. Which one matters most depends on the cost of errors: in disease screening a false negative is usually worse, so recall is emphasised, while in spam filtering a false positive may be worse, so precision is emphasised.

Part 6: Thresholds, ROC curve and AUC
- Many classifiers output a score or probability, and a threshold converts it into a class. Raising the threshold usually increases precision and lowers recall.
- The ROC curve plots the true positive rate against the false positive rate for every threshold. The false positive rate is FP divided by (FP + TN).
- The area under the ROC curve (AUC) summarises performance across thresholds. An AUC of 0.5 corresponds to random guessing and an AUC of 1.0 to a perfect ranking.

Part 7: Regression metrics
- Mean absolute error (MAE) is the average of the absolute differences between predictions and true values.
- Mean squared error (MSE) is the average of the squared differences. Root mean squared error (RMSE) is its square root and is in the same units as the target. Squaring makes MSE and RMSE more sensitive to large errors than MAE.
- R squared measures the proportion of the variance in the target that the model explains. A value of 0 means the model does no better than predicting the mean.

Part 8: Practical checklist
- Split the data before any preprocessing that learns from it, to avoid leakage.
- Choose a metric that matches the real cost of errors, and compare against a simple baseline.
- Report variation across folds, not only one number.
