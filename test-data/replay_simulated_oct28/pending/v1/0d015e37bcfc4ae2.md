Lecture 14: TCP Connection Management
- TCP is a connection-oriented, reliable, byte-stream transport protocol. It provides ordered delivery and retransmits lost segments.
- A connection is established with a three-way handshake: the client sends SYN, the server replies SYN-ACK, and the client replies ACK.
- Sequence numbers label bytes so the receiver can reorder segments and detect loss; acknowledgements (ACKs) tell the sender what has been received.
- Flow control uses the receiver's advertised window (rwnd) so the sender does not overwhelm the receiver's buffer.
- Congestion control protects the network. Slow start begins with a small congestion window (cwnd) and roughly doubles it every round trip until it reaches the slow-start threshold (ssthresh); then congestion avoidance increases cwnd by about one segment per round trip.
- When a packet loss is detected by a timeout, TCP sets ssthresh to half of cwnd and restarts slow start.
- A connection is closed with FIN and ACK segments exchanged in each direction (four-way teardown).
- UDP, by contrast, is connectionless and gives no delivery guarantee.
