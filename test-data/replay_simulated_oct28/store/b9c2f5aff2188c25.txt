{"summary": "Time complexity describes how running time grows with input size n. Big-O gives an upper bound: f(n) is O(g(n)) if f(n) <= c*g(n) for all n >= n0 for some constants c, n0. Common classes: O(1), O(log n), O(n), O(n log n), O(n^2), O(2^n). Constants and lower-order terms are dropped. Binary search is O(log n) because each step halves the range; linear search is O(n). Merge sort is O(n log n) worst case; insertion sort is O(n^2) worst case but O(n) when sorted. Big-Omega is a lower bound; Big-Theta is tight. Space complexity measures extra memory use."}
