The update rule is w_new = w_old - alpha * dL/dw, where alpha is the learning rate. A learning rate that is too small makes convergence slow, and one that is too large can overshoot and diverge. Batch gradient descent uses the whole training set per step and is stable but slow on large data. Stochastic gradient descent uses one example per update, which is fast and noisy, and the noise can help escape shallow local minima. Mini-batch gradient descent uses a small batch, such as 32 or 64 examples, and is the usual practice. For convex losses such as mean squared error in linear regression, gradient descent with a suitable learning rate reaches the global minimum.
