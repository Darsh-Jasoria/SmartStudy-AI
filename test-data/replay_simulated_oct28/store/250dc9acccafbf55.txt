{"summary": "The scheduler picks the next ready process and the dispatcher switches the CPU to it via a context switch. Preemptive scheduling can take the CPU from a running process; non-preemptive does not. FCFS runs processes in arrival order but suffers the convoy effect. SJF minimises average waiting time but needs burst prediction and can starve long processes. Round Robin gives each process a fixed quantum, then requeues it; large quanta act like FCFS, tiny ones add overhead. Priority scheduling runs the highest priority first; aging solves starvation. Metrics: turnaround, waiting and response time."}
