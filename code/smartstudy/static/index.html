The task

Input: lecture notes or slide text, with an optional subject and difficulty level. Output: a word-limited summary, key terms with definitions, and practice questions (MCQ, short answer, true/false) with an answer key, where every term and answer carries a quote from the notes. Missing information is reported with a warning, not invented.

Prompt-engineering techniques used

Role + constraintsTeaching-assistant role, “use only the notes”, word limit
Structured outputStrict JSON schema, validated in code
Few-shot with a negative caseWorked example; distractors are not terms
Prompt chainingOutline → generate → moderate → length guard
Source groundingVerbatim quote per item, checked by code
Over-generate and filterN+2 questions, keep the first N valid
Escape hatchFewer questions plus a warning instead of inventing
Rubric-based A/B evaluationSix versions, one gold-labelled test set

    Research basis

    Dunlosky et al. (2013) identified practice testing and distributed practice as highly useful learning techniques; the Questions, Quiz and Plan tabs follow that idea. This project evaluates the quality of generated study packs; it makes no claim about learning gains.

    Responsible use

    Output is a revision aid, not a source of truth. Items whose quote cannot be found are flagged, questions that fail review are dropped, and fewer questions are returned (with a warning) rather than padding with unverified ones. Do not paste personal data; nothing is stored.
